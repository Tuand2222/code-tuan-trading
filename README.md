# Code Tuan Trading 📈

> AI-enabled trading application with GitHub workflow integration

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/Tuand2222/code-tuan-trading.git
cd code-tuan-trading

# Install dependencies
npm install

# Run development server
npm run dev

# Run tests
npm run test

# Build for production
npm run build
```

## 📋 Repository Rules

✅ **Workflow:**
- Create feature branch
- Make changes
- Submit Pull Request
- Wait for approval
- Merge to main

❌ **Prohibited:**
- Direct commits to `main`
- Force pushes
- Merging without review

## 🤖 For AI Assistants

**Permissions:**
- ✅ Read & Write Contents
- ✅ Read & Write Pull Requests
- ✅ Read Metadata
- ✅ Read & Write Issues

**Workflow:**
1. Create branch: `feature/description`
2. Make changes and commits
3. Push to remote
4. Create Pull Request
5. Wait for approval & merge
